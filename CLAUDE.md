## archsafe Englishization Contract

For any localization, Englishization, i18n, multilingual UI, locale
routing, or localized PDF/report work, read and follow
archsafe-real/docs/englishization-contract.md before modifying code.

Do not invent a different localization architecture without checking
the canonical contract first.

This repository uses the Static HTML pattern described in that
contract.


After implementation, explicitly report the applicable contract
requirements and their verification status.
